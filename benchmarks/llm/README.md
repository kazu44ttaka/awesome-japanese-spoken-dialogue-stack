# LLM（準備中）

日本語の知識や推論の力は既存のリーダーボード（Nejumi、Swallow）に任せ、ここでは音声対話で効く値を測ります。

予定している指標：

- **最初のトークンまでの時間（TTFT）**：ユーザーが話し終えてから返事が始まるまでの時間に直結する
- **トークンの出る速さ（tokens/s）**：読み上げ（TTS）より遅いと途中で詰まる
- **短い返事の安定性**：音声対話向けの短い応答を指示どおりに返せるか

測り方：同じプロンプトを、同じ PC で LM Studio / llama.cpp / vLLM などから OpenAI 互換 API で投げ、ウォームアップを除いて複数回の中央値と最悪値をとる。
